# Starbucks Sales Prediction Using Decision Tree

This repository contains a Machine Learning project that predicts outcomes using a **Decision Tree Regressor** model. The model was successfully built and evaluated inside a Kaggle Notebook environment using a Starbucks dataset.

## Model Details
- **Model Type:** Decision Tree Regressor
- **Features Used:** Quantity, Price
- **Metrics Evaluated:** Squared Error (MSE), Sample counts, and Node values.

## Project Structure
- `notebookc82bbb9376.ipynb`: The main Kaggle notebook containing data preprocessing, visualization, and model training.
- `README.md`: Project documentation.
- `.gitignore`: Specifies intentionally untracked files to ignore.

## Requirements
To run this notebook locally, you will need:
- Python 3.x
- Jupyter Notebook / Lab
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib / Seaborn
